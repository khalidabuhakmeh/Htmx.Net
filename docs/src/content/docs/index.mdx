<p class="home-lead">
htmx sends its state in request headers and reads it back from response headers. htmx.NET turns both sides into typed C# — so you detect htmx requests, read the triggering element, set <code>HX-*</code> response headers, and generate URLs from ASP.NET routing, instead of parsing and concatenating strings by hand.
</p>

## An example

Read the incoming htmx request and answer with typed response headers, instead of parsing strings and building JSON by hand.

```csharp
// Detect an htmx request and read the element that triggered it.
if (Request.IsHtmx(out var htmx))
{
    // e.g. "save-button"
    var id = htmx.SourceElement?.Id;
    // Full or Partial
    var type = htmx.RequestType;
}

// Set HX-* response headers fluently instead of building strings.
Response.Htmx(h => h
    .PushUrl("/items/5")
    .WithTrigger("saved", new { id = 5 }));
```
